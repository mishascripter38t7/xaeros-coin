# 🪙 Xaeroscoin (XCN)

Official decentralized blockchain, mining node, and exchange ecosystem for **Xaeroscoin**.

## 🚀 Features
* **Ticker:** `XCN`
* **Proof-of-Work (PoW) Mining:** Dynamic difficulty algorithm — starts easy and gets harder as more blocks are mined.
* **Donatello Integration:** Real-world fiat gateway (UAH) for trading and buying XCN.
* **Open Source:** Fully transparent blockchain built on Node.js.

## 🌐 API Endpoints
* `GET /chain` — View the entire XCN blockchain.
* `POST /mine` — Mine a new block and earn XCN rewards.
